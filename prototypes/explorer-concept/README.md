# Explorer concept prototype (synthetic)

A clickable look-and-feel exploration of the Panoptes explorer ("Ops Desk"), following `docs/explorer-ui-concept.md`.

**This is a synthetic design exploration, not the explorer implementation.** No UI framework, schema or Mac technology is selected. All data in `data/persona.json` is invented (Subject EX-01, fictional Port Meridian) and is generated by `spikes/synthetic_persona.py`.

## View it

From this folder:

```bash
python -m http.server
```

then open <http://localhost:8000>. Opening `index.html` via `file://` will show an in-page error, because browsers block `fetch` of the local JSON.

The page is a single file (inline CSS and JS, no framework, no build step). It loads IBM Plex fonts from Google Fonts with system fallbacks; if offline, the fallbacks are used.

## What is in it

Screens (hash routes): `#map`, `#timeline`, `#dossier`, `#graph`, `#coverage`, `#investigation`, `#control`, `#briefing`.

- Keys 1-6 switch lenses (Evidence, Coverage, Time-heat, Uncertainty, Privacy exposure, Noir/focus). `G` then `M T D L C I P B` jumps between screens. `Ctrl/Cmd+K` opens the command palette; `?` lists shortcuts.
- The STYLE toggle (CRT scanlines) is off by default, affects only Map and Briefing, and honours reduced-motion.
- Pause toggles, the delete preview and the briefing are simulated or templated: no collection, deletion or LLM call happens.
- The "LOCAL ONLY*" banner is a concept element; this page fetches web fonts, so a real build must verify that claim.

Not evidence that any real capture source works. Do not put real participant data in this folder.
